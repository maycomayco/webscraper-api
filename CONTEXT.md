# CONTEXT.md

## Glossary

- **Descubrimiento de música**: Recomendaciones extraídas de un artículo de
  IndieHoy y buscadas en YouTube Music para ofrecer enlaces de escucha.
- **Track encontrado**: Canción con una coincidencia en YouTube Music. No
  implica que se haya agregado a una playlist.
- **Track no encontrado**: Recomendación para la que no se encontró una
  coincidencia válida en YouTube Music.
- **Modo anónimo**: Búsquedas sin una cuenta de YouTube. No crea playlists
  ni modifica datos de una cuenta.
- **Telegram notifier**: Consumidor externo que envía semanalmente las
  recomendaciones al usuario.
